# Security policy

## Supported versions

| Version | Security fixes |
|---------|----------------|
| 1.x     | Yes |
| < 1.0   | No |

## Reporting a vulnerability

**Do not** report security issues in public GitHub Issues.

1. Prefer a private [GitHub Security Advisory](https://github.com/Blair-Shang/ensis-ui/security/advisories/new) if Advisories are enabled.
2. Otherwise contact a repository maintainer privately.

Please include:

- Affected package version or git tag
- Impact
- Reproduction steps or a proof of concept
- A suggested fix (optional)

We aim to acknowledge reports within 7 days and to ship a fix or mitigation as soon as we can. After a release, we can credit the reporter in the CHANGELOG or advisory if you want that.

# 安全策略

## 支持的版本

| 版本 | 是否支持安全修复 |
|------|------------------|
| 1.x  | 是 |
| < 1.0 | 否 |

## 报告漏洞

请**不要**通过公开 Issue 报告安全漏洞。

1. 优先使用仓库的 [GitHub Security Advisories](https://github.com/Blair-Shang/ensis-ui/security/advisories/new)（若已开启）。
2. 否则请私下联系仓库维护者。

报告请尽量包含：受影响的包版本 / git tag、影响说明、复现步骤或概念验证、修复建议（可选）。

我们会力争在 7 日内确认收到报告，并尽快发布修复或缓解措施。修复发布后，可按报告人意愿在 CHANGELOG / advisory 中致谢。
